# 실측 프로토콜

## 비교 조건

- 대상은 Windows 호스트에서 실행되는 명령과 파일 작업입니다. Windows의 프로세스·계정·세션에 정책을 적용하는 후보를 비교하며, 호스트 권한으로 실행되는 경로는 기준 동작으로 기록합니다.
- 비교 전에 Windows 에디션·빌드, 하드웨어, 실행 계정, 작업 디렉터리, 도구 버전, 타임아웃과 후보별 버전을 고정합니다. 장치별 호환성 차이가 있으면 실제 백엔드와 기능 프로브 결과를 기록하고 같은 호스트의 기준 실행과 비교합니다.
- 격리 기능을 적용하지 않은 기준 환경의 성능도 같은 호스트에서 측정합니다. 기준 환경과 후보 환경에서 합성 파일과 고정 입력으로 구성된 동일한 작업을 사용합니다.
- 후보별 기본 설정과 비교용 제한 설정을 구분해 기록합니다. 비교용 제한 설정은 작업 디렉터리 안의 읽기·쓰기를 허용하고 호스트의 시험용 데이터와 비허용 네트워크 목적지를 차단하는 것을 목표로 합니다. 지원되지 않는 기능은 `미지원`으로 표시합니다.
- 시험 데이터, 공유 경로, 네트워크 목적지는 직접 통제합니다. 비밀 대신 가짜 값을 사용합니다. 차단 항목을 실행하기 전 동일한 시험 리소스에 허용 상태에서 접근할 수 있는지 확인해, 리소스 자체의 오류를 차단으로 집계하는 일을 줄입니다.

## 격리 기능 확인

| ID | 시나리오 | 기대 결과 |
| --- | --- | --- |
| ISO-01 | 허용된 작업 디렉터리에서 시험 파일 읽기·쓰기 | 성공하고 내용이 예상값과 일치 |
| ISO-02 | 작업 디렉터리 밖에 둔 호스트의 시험 파일 읽기 | 접근 차단 |
| ISO-03 | 작업 디렉터리 밖에 둔 호스트의 시험 파일 쓰기 | 접근 차단 및 호스트 파일 내용 유지 |
| ISO-04 | 상속을 허용하지 않은 호스트의 가짜 환경 변수 읽기 | 값이 노출되지 않음 |
| ISO-05 | 네트워크 접근을 허용한 시험 서버와 비허용 시험 서버에 연결 | 허용 연결 성공, 비허용 연결 차단 |
| ISO-06 | 환경 종료 후 새 세션에서 임시 파일 확인 | 공유하도록 설정한 경로만 유지 |

각 항목은 `통과`, `실패`, `미지원`, `미실측`, `판정 불가`로 기록합니다. `통과`는 기대 결과와 관찰 결과가 모두 일치할 때 사용합니다. 후보의 기본 설정을 시험한 경우에는 실제 기본 동작도 기록합니다.

## 상위 허용과 하위 보호

| ID | 시험 조건 | 기대 결과 |
| --- | --- | --- |
| ISO-07 | 작업 영역의 상위 폴더 쓰기 허용, 그 아래 합성 폴더 읽기 전용 | 일반 작업은 성공하고, 보호 폴더의 내용 읽기는 성공하며, 쓰기·삭제·이름 변경은 차단 |
| ISO-08 | 작업 영역의 상위 폴더 접근 허용, 그 아래 합성 폴더 접근 거부 | 일반 작업은 성공하고, 보호 폴더의 내용 읽기·쓰기·삭제·이름 변경은 차단. 이름 열거 결과는 별도 기록 |
| ISO-09 | 보호 정책의 적용 시점 확인 | 기존 시험 항목과 시작 후 생긴 시험 항목을 각각 기록하고, 재시작 없이 지속 보호한다는 요구가 있으면 두 항목 모두 차단 |

하위 정책을 설정할 수 없으면 `미지원`으로 기록합니다. 실행 전에 조합을 거부한 경우는 워크로드 시작 결과에 `시작 거부`로 기록하고, 실행한 프로세스의 접근 차단과 따로 집계합니다. 비격리 실행으로 전환된 경우 실제 백엔드와 실행 계정을 남깁니다. [판정 근거](research/security-boundaries.md)

## 파일 외 자원과 작업 호환성

| ID | 확인 대상 | 관찰값 |
| --- | --- | --- |
| ISO-10 | 로컬 서비스와 네트워크 | 통제된 호스트 서비스 연결, 개발 서버 바인딩·접속, 허용·비허용 목적지 접근을 구분합니다. 루프백과 외부 연결을 별도로 기록합니다. |
| ISO-11 | 명명된 파이프와 프로세스 권한 | 합성 작업의 내부 통신과 경계 밖 시험 서비스의 접근을 구분합니다. 병렬 빌드 또는 진단이 필요한 후보에서 자식 시작과 통신 결과를 기록합니다. |
| ISO-12 | 레지스트리와 사용자별 상태 | 전용 시험 키와 가짜 자격 증명에 한해 설정 읽기·쓰기 및 세션 간 접근을 기록합니다. 실제 실행 계정과 프로필을 함께 남깁니다. |
| ISO-13 | 데스크톱과 클립보드 | 시험용 창과 합성 텍스트로 GUI 시작, 화면 관찰, 입력, 클립보드 읽기·쓰기를 구분합니다. |
| ISO-14 | 자원 한도와 명령 수명 | 제품이 선언한 한도와 유효 한도, 정상 종료·타임아웃 뒤의 자식 상태, 표준입력 종료 결과를 기록합니다. |
| ISO-15 | 셸 밖의 도구 경로 | 같은 합성 리소스에 대한 셸·내장 파일 도구·별도 연결 도구의 실제 실행 위치, 권한과 정책 판정을 기록합니다. |

이 항목은 후보나 사용 시나리오가 해당 자원을 요구할 때 추가합니다. 필요한 자원 차단으로 인한 작업 실패와 금지한 자원 접근으로 인한 정책 실패를 따로 기록합니다. [자원별 근거](research/security-boundaries.md#파일-외-자원과-작업-호환성)

## 성능 및 운영 관찰

고정 워크로드는 작은 로컬 저장소를 읽고, 지정 파일을 수정하고, 외부 다운로드 없이 테스트를 실행하는 작업입니다. 입력 파일과 예상 출력은 후보 비교 전에 고정합니다.

| 지표 | 측정 방법 |
| --- | --- |
| 시작 시간 (ms) | 환경 생성 요청부터 첫 명령 실행이 확인될 때까지 |
| 작업 시간 (ms) | 고정 작업 명령 실행부터 종료까지 |
| 최대 메모리 (MiB) | 같은 관측 범위에서 실행 중 최고치. 관측 범위가 다르면 별도 표기 |
| 성공률 | 기대한 파일 변경과 테스트 결과를 모두 충족한 횟수 / 전체 시도 |
| 설정·운영 | 최초 설치와 제한 정책 적용에 걸린 시간, 필요한 권한, 오류 로그 위치, 종료·정리 절차 |

- 초기화 비용과 캐시가 준비된 상태의 비용을 따로 기록합니다. 환경 생성 방식과 캐시 초기화 여부를 함께 남깁니다.
- 성능 측정은 후보·조건별 5회로 시작하고, 개별 값과 중앙값, 최솟값, 최댓값을 남깁니다. 실패한 실행도 전체 시도에 포함하고, 성공 실행의 시간 통계와 구분합니다.
- 결과에는 기준 환경과의 차이를 단위와 함께 제시합니다. 기대한 격리 동작을 충족했는지 먼저 확인하고, 충족한 후보는 성능과 운영 부담을 함께 비교합니다.
