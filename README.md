# 리서치 프로젝트

질문, 조사 방법, 근거, 결론을 프로젝트별로 기록합니다. 이 목록에서 진행 상태를 확인하고, 각 프로젝트의 README에서 조사 범위와 다음 작업을 확인할 수 있습니다.

## 프로젝트 목록

| 프로젝트 | 상태 | 다음 작업 |
| --- | --- | --- |
| [코덱스 하네스 개선](projects/codex-harness-improvement/README.md) | 준비 | 실제 작업 2개를 골라 전달 방식 프롬프트 비교 |

## 운영 방식

1. **준비** — `projects/주제명/`에 프로젝트 폴더를 만들고 [프로젝트 시작 양식](templates/project.md)에 조사 질문, 범위, 완료 기준을 작성합니다. 위 목록에 추가합니다.
2. **진행** — 조사 방법을 확정합니다. 실측 프로젝트는 `protocol.md`에 환경, 지표, 판정 기준을 기록하고, [실행 양식](templates/run.md)에 따라 `runs/YYYY-MM-DD-NN.md`를 남깁니다. 문헌 조사는 출처와 해당 주장을 함께 기록합니다.
3. **검토** — `findings.md`에 결론과 근거를 연결하고, 실행 조건 차이와 빠진 항목이 판단에 미치는 영향을 적습니다. 조건을 바꿔 재실행하면 기존 기록을 보존하고 새 실행 ID를 부여합니다.
4. **완료** — 프로젝트의 완료 기준을 확인하고 목록에 상태를 반영합니다. 중단할 때는 상태를 **보류**로 바꾸고 재개 조건을 적습니다.

상태와 다음 작업은 위 목록에서 관리합니다. 프로젝트별 상세 맥락은 각 README에 둡니다. 원시 로그와 환경 스냅샷은 `local/`에 보관할 수 있습니다. 공개 저장소에는 재현에 필요한 설정과 함께 비밀·개인정보·내부 환경 식별자를 제거한 근거를 기록합니다.
