# 코덱스 하네스 개선

자주 하는 작업을 Codex에 더 잘 맡길 수 있도록 모델, 프롬프트, 스킬, 플러그인 조합을 실험합니다. 원하는 결과를 얻는 데 필요한 추가 지시와 수정 시간을 줄이고, 모델별 기본 설정과 작업별로 추가할 설정을 정합니다.

## 조사 질문

1. 현재 설정에서 코딩, 글쓰기, 디자인, 업무 흐름, 판단 중 어떤 부분에 가장 자주 개입하는가?
2. 어떤 프롬프트·스킬·플러그인이 결과물이나 작업 과정을 개선하는가? 어느 작업에서 효과가 나타나는가?
3. 같은 설정 변경의 효과가 모델마다 어떻게 달라지는가?

## 범위와 산출물

- [실험 계획](protocol.md#평가표)의 평가표에서 작업에 맞는 항목을 고릅니다. 글쓰기는 내용과 전달 방식을 각각 평가합니다. 전달 방식의 말투, 간결함, 정보 순서, 예시는 코딩 결과 보고와 업무 진행 보고에도 적용합니다.
- [실행 양식](../../templates/run.md)을 사용해 `runs/`에 실행 조건, 결과, 평가 근거를 남깁니다.
- 비교가 끝나면 `findings.md`에 모델별 기본 설정, 작업별로 추가할 설정, 판단 근거와 적용 범위를 기록합니다.

## 완료 기준

- [ ] 자주 하는 작업의 완료 조건을 정하고 현재 설정으로 실행했다.
- [ ] 프롬프트, 스킬, 플러그인 후보를 비교하고 개선 효과와 비용을 기록했다.
- [ ] 채택할 설정의 효과를 새 과제와 추가 모델에서 확인하고, 확인한 모델과 작업 범위를 기록했다.
- [ ] 반복해서 쓸 설정과 작업에 따라 추가할 설정을 근거와 함께 정리했다.
