# 결과 및 판단

일곱 서비스의 [Windows 네이티브 실행 경로](README.md#windows-서비스별-조사)와 [Windows 격리 기술](research/README.md)을 문서와 소스로 조사했습니다. 실측 결과는 아직 없습니다.

문헌·소스 단계의 종합 결론과 사례는 [조사 보고서](report.md)에 정리했습니다.

| 조사 질문 | 확인할 결과 | 근거 |
| --- | --- | --- |
| 격리 범위 | 후보별 필수 항목 판정과 설정 차이 | [보안 한계 문헌·소스 검토](research/security-boundaries.md) · 실행 기록 추가 예정 |
| 작업 호환성 | 병렬 빌드, 로컬 서비스, 프로필별 설정, UI와 백그라운드 작업에 필요한 자원 | [파일 외 자원 검토](research/security-boundaries.md#파일-외-자원과-작업-호환성) · 실행 기록 추가 예정 |
| 성능 비용 | 같은 호스트의 기준 실행 대비 시작 시간, 작업 시간, 메모리, 성공률 | 실행 기록 추가 예정 |
| 운영 부담 | 필수 권한, 초기 설정 시간, 로그 접근과 정리 절차 | 실행 기록 추가 예정 |

실행 후 후보별 버전·정책과 실행 ID를 연결합니다. 사용 시나리오별로 적용 가능 조건, 판단을 제한하는 미실측 항목, 추가 확인이 필요한 항목을 기록합니다.
