# 에이전트 격리 솔루션 실측조사

코딩 에이전트가 명령을 실행하고 파일을 수정할 때, 작업 권한을 어디까지 제한할 수 있는지와 그 제약이 실행 비용과 운영에 어떤 영향을 주는지 비교합니다.

[Windows 네이티브 에이전트 샌드박스 조사 보고서](report.md)에서 핵심 결론, 사례와 배경지식을 읽을 수 있습니다. QwenPaw의 Restricted Token과 AppContainer를 실측한 결과는 [QwenPaw 실측 보고서](report-qwenpaw-backends.md)에 있습니다. Restricted Token 계열 네 구성의 비교 실측 계획은 [실측 계획](plan-token-backends.md)에 있습니다. 네 구성의 결과는 [결과 및 판단](findings.md#restricted-token-네-구성-실측-2026-11-25)에 있습니다. 실행 기록은 두 개로 나뉩니다. UAC 없이 측정한 세 구성(QwenPaw 비관리자, Codex `unelevated`·`elevated`)은 [2026-11-25-01](runs/2026-11-25-01.md), 사용자가 UAC를 승인해 측정한 QwenPaw 관리자 구성과 관리자 권한 항목은 [2026-11-25-02](runs/2026-11-25-02.md)입니다.

## 조사 질문

1. 작업 디렉터리 내부에서 필요한 작업을 수행하면서 호스트 파일, 환경 변수, 네트워크, 실행 종료 후 상태를 어느 범위까지 통제할 수 있는가?
2. 동일한 작업을 실행할 때 환경 시작 시간, 작업 시간, 자원 사용량과 실패율은 어떻게 달라지는가?
3. 초기 설정, 정책 변경, 로그 확인, 실행 환경 정리에 어느 정도의 운영 작업이 필요한가?

## 범위와 산출물

- 비교 범위는 **Windows 네이티브에서 실행되는 에이전트 명령과 파일 작업**입니다. Windows가 해당 프로세스·계정·세션에 적용하는 격리를 조사합니다. WSL2, Linux 컨테이너, 외부 VM과 원격 실행은 비교 범위에서 제외합니다.
- 첫 라운드는 고정된 로컬 워크로드로 실행 계층을 측정합니다. 에이전트와 연동하는 경우에는 같은 모델·버전·작업 지시를 사용하고 관찰 결과를 별도로 기록합니다.
- [실측 프로토콜](protocol.md)에 통제 조건, 검증 항목과 측정 방법을 기록합니다. 실행 기록은 [실행 양식](../../templates/run.md)을 복사해 이 프로젝트의 `runs/`에 추가합니다.
- [결과 및 판단](findings.md)에서 질문별 결론과 근거를 연결합니다.
- [Windows 네이티브 격리 조사](research/README.md)에서 에이전트별 실행 경로와 Windows 격리 기술의 적용 범위를 확인할 수 있습니다.

## Windows 서비스별 조사

2026-11-23 기준으로 최근 안정 릴리스와 공식 문서를 확인했습니다. Windows 호스트에서 실제 명령을 실행하는 프로세스를 기준으로 백엔드를 비교합니다. 표의 결과는 문서와 소스에 근거하며, 성능과 실제 적용 여부는 설치 조건별로 측정합니다.

| 서비스 | 조사 기준 안정 릴리스 | 네이티브 기본 동작과 선택 가능한 격리 |
| --- | --- | --- |
| [Codex](research/agents/codex.md) | CLI 0.171.0 | 호환 소비자 데스크톱은 MXC 우선. 레거시는 관리자 준비형 샌드박스와 제한 토큰을 사용하며 CLI 선택은 설정에 따름 |
| [Claude Code](research/agents/claude-code.md) | 2.1.330 | 도구 승인 후 Windows 사용자 권한으로 셸 실행 |

| [OpenClaw](research/agents/openclaw.md) | Gateway 2026.11.6 · Hub 2026.11.3 | Gateway 도구 MXC는 선택형. Windows 노드에 별도 MXC 경로가 있으며, 호환 PC의 Store Gateway는 IsolationSession에 배치 |

OS의 파일·프로세스 제약과 도구 승인 결과를 각각 기록합니다. Windows 호스트 사용자 권한으로 실행되는 경로는 기준 동작으로 기록합니다. 결과에는 도구 종류, 실제 백엔드와 실행 계정을 함께 적습니다.
