# 코덱스 하네스 개선

Codex에 작업 지시와 문맥을 전달하고, 도구를 사용해 변경을 만들고, 검증 결과를 확인하기까지의 과정을 개선합니다. 대표 작업을 반복해 현재 흐름에서 자주 발생하는 문제를 찾고, 개선 전후의 결과를 같은 기준으로 비교합니다.

## 조사 질문

1. 작업 지침 탐색, 도구 실행, 변경 검증과 인계 중 어느 단계에서 재시도와 사용자 개입이 가장 많이 발생하는가?
2. 어떤 하네스 설정이나 작업 흐름을 바꾸면 기존 동작을 보존하면서 완료율과 검증 품질을 높일 수 있는가?
3. 변경이 적용될 환경과 재현 조건은 무엇이며, 소요 시간과 사용자 개입 횟수는 어떻게 달라지는가?

## 범위와 산출물

- 작업 지침과 컨텍스트 전달, 도구 호출과 오류 복구, 검증과 세션 인계를 초기 조사 범위로 둡니다.
- 대상 Codex 환경과 버전, 설정, 대표 작업, 완료 판정 기준을 정하고 개선 전 실행 기록을 남깁니다.
- 대표 작업은 지침을 따라 수행하는 파일 변경, 실패한 도구 호출에서 복구하는 작업, 테스트를 실행하고 검증 결과를 설명하는 작업으로 시작합니다.
- 우선순위가 높은 개선을 적용한 뒤 같은 입력과 실행 조건으로 재실행합니다. 완료율, 사용자 개입 횟수, 경과 시간, 필요한 검증의 수행 여부를 기록합니다.
- 실험 기록은 [실행 양식](../../templates/run.md)을 사용합니다. 개선안과 근거, 적용 조건은 비교 결과가 나온 뒤 정리합니다.

## 완료 기준

- [ ] 대상 환경과 대표 작업을 정하고 현재 동작을 재현했다.
- [ ] 관찰한 실패 또는 마찰을 바탕으로 개선안을 선택하고 적용했다.
- [ ] 같은 조건에서 개선 전후를 비교해 결과와 회귀 여부를 기록했다.
- [ ] 적용과 재현에 필요한 설정, 남은 문제, 변경을 되돌리는 방법을 기록했다.
